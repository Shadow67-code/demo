# Prince Furniture — multi-page showroom website

## Run on Windows 10
1. Download and extract this ZIP.
2. Open the `prince-furniture-website` folder in VS Code.
3. Open `index.html` in Chrome. Click product categories to visit the additional pages.

No Python, Node.js, or package installation is required.

## Pages included
- `index.html` — home page and showroom location
- `products.html` — all furniture collections
- `sofas.html` — sofas and seating
- `beds.html` — beds and bedroom
- `dining.html` — dining furniture
- `office.html` — office furniture
- `living.html` — living room furniture
- `storage.html` — storage and home accents
- `style.css` — shared responsive design
- `script.js` — mobile menu and current year

Product imagery is illustrative. There is no product inventory, shopping cart, or checkout yet. Verify the exact store name, address, phone number, hours, stock and prices before publishing. This is an independent design concept, not affiliated with Nilkamal.
